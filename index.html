Create timelines with ease.

TimeNav is a timeline creation app for macOS that helps you visualize and organize events over time. Build timelines for projects, history, personal milestones, or any sequence of events with an intuitive document-based workflow.

Endless Customization

Choose horizontal or vertical orientation. Select from styles like minimal, gradient, dotted, dashed, or wavy. Tailor event markers with shapes—circles, squares, diamonds, stars, hearts, arrows, pins—adjust sizes and fills to match your vision.

Precise Control

Position labels exactly where needed. Fine-tune fonts, colors, and connector styles. Every element adapts to your visual style, ensuring timelines that communicate clearly and elegantly.

Seamless Workflow

Each timeline saves as its own file. Print directly or export to multiple formats for presentations and documentation. Search events effortlessly, with improved undo/redo for fluid editing.

Refined Performance

Version 1.2.1 brings new icons and colors, enhanced export options, and a search field for quick event access. Smoother UX, better performance, and rock-solid reliability.

How It Works

1. Start a New Timeline

Open TimeNav and create a document. Choose orientation and style to set the foundation.

2. Add and Customize Events

Insert events via the list. Pick shapes, colors, sizes, and labels. Search to find and edit quickly.

3. Refine and Preview

Adjust connectors, fonts, and positioning. Use undo/redo for precision. Preview in real time.

4. Export or Print

Save as a file, print, or export to your preferred format. Ready for sharing or documentation.
